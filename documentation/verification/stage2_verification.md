### XSim warnings
`WARNING: [XSIM 43-3373] ... System function $value$plusargs is used as system task` - tb_rv_pipe.sv lines 137-139 (and tb_rv_core.sv lines 113-115, Stage 1, since Stage 1). Cause: `void'($value$plusargs(...))` for `EXPECT_CAUSE`, `CHECK_GP`, `TIMEOUT`. Effect on correctness: none observed; negative tests need `EXPECT_CAUSE` and `CHECK_GP` to be parsed and pass in XSim. `TIMEOUT` parsing is not independently evidenced (no test reaches the default timeout of 2,000,000 cycles). Proposed minimal fix (not applied; awaiting authorization): declare `int plusarg_ok;` and write `plusarg_ok = $value$plusargs("EXPECT_CAUSE=%d", expect_cause);` (likewise `CHECK_GP`, `TIMEOUT`).
